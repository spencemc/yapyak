---
title: YAP0056
name: Unsupported display name
severity: warning
summary: format.displayName() code is rejected by the runtime
---

`format.displayName(code, type)` is called with a code your `Intl` runtime rejects for that type: a language tag, region, script, currency, calendar, or date-time field it cannot parse. yapyak renders the code itself.

Pass a code of the named type in its canonical form, such as `sv`, `DE`, `Latn`, or `EUR`.
